# Ketentuan soal dan kamera

- Sesuai permintaan pemilik tanggal 21 November 2026: Paket TKA 24 dan paket berikutnya memakai tepat lima opsi A–E, satu jawaban benar. Paket sebelum 24 tidak ikut diubah.
- Setiap pengecoh harus spesifik pada soal, masuk akal, dan berbeda dari kunci. Jangan sekadar menambahkan pilihan umum seperti “semua benar”. Periksa panjang jawaban agar kunci tidak mudah ditebak dari bentuknya.
- Generator lokal pada direktori induk `buat_tka.py` menolak paket mulai nomor 24 yang belum memakai lima opsi. Sumber Paket 24: `buat_paket24.py` dan `opsi_e_paket24.json`. Bangun ulang menggunakan `python3 build_web.py` setelah sumber dan sidik pembahasan matematika diperbarui.
- Kamera ujian dengan persetujuan peserta dan orang tua mengambil foto setiap satu menit, bukan lima menit. File foto wajib privat; jangan masukkan foto ke Git atau membagikan folder secara publik. Batas 180 foto per sesi.
- Jalankan tes kamera, backend kamera, sesi, rekap grafik, dan lima opsi; jangan mengirim nilai atau foto pribadi untuk pengujian produksi.
